🎨 LAYOUTS STRUCTURE
===============================================================================

1. layouts/public.blade.php
   - Used for: Public website pages
   - Features: Bootstrap 5, AOS animations, responsive design
   - Target: General visitors

2. layouts/admin.blade.php  
   - Used for: Admin panel (superadmin & admin roles)
   - Features: Sidebar navigation, DataTables, Charts
   - Target: Administrators

3. layouts/juri.blade.php
   - Used for: Jury dashboard and scoring
   - Features: Submission review, scoring forms
   - Target: Competition judges

4. layouts/peserta.blade.php
   - Used for: Participant dashboard
   - Features: Registration, submission forms
   - Target: Competition participants

5. layouts/app.blade.php
   - Used for: General authenticated pages
   - Features: Basic auth layout
   - Target: All authenticated users

6. layouts/caturnawa-2025.blade.php
   - Used for: Special themed pages
   - Features: UNAS Fest 2025 branding
   - Target: Event-specific pages

7. layouts/modern.blade.php
   - Used for: Modern design pages
   - Features: Contemporary UI elements
   - Target: Enhanced user experience

8. layouts/simple.blade.php
   - Used for: Minimal pages (auth, errors)
   - Features: Clean, minimal design
   - Target: Authentication flows

🔧 API ROUTES (AJAX/JSON responses)
===============================================================================

All API routes return JSON responses (no views/layouts):

/api/achievements - Achievement data
/api/leaderboard - Leaderboard data
/api/competitions/{competition}/description - Competition descriptions
/api/submissions/{submission} - Submission details
/api/user/session - User session with deadline reminders
/api/user/dismiss-reminder - Dismiss deadline reminders
/api/judging/form - Judging form configuration
/api/judging/score - Save judging scores
/api/invoices - Invoice list for finance
/api/invoices/{payment_id} - Invoice details
